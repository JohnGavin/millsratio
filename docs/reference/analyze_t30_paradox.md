# Generate Data for t(30) Paradox Analysis

Generate Data for t(30) Paradox Analysis

## Usage

``` r
analyze_t30_paradox(x_range = c(0, 5), n_points = 200)
```

## Arguments

- x_range:

  Range of x values

- n_points:

  Number of points

## Value

Data frame comparing t(30) and normal distributions

## Examples

``` r
paradox_data <- analyze_t30_paradox()
```
